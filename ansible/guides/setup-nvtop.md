(Neat Video card TOP) is the gold standard for Ubuntu. It shows beautiful real-time graphs of CUDA core utilization and memory.

Installation:

sudo apt update
sudo apt install nvtop

Usage: 

Just type nvtop in your terminal.

What use it for RAG?

It allows you to see which specific process (e.g., your Python script, Ollama, or vLLM) is hogging the compute cores and how much VRAM is being consumed by your vector database versus your model.
